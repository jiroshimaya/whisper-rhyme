# Whisper tiny / small / large-v3のラップ誘導比較

同じ入力で360回比較したところ、tinyとsmallはlarge-v3より長く出力した。smallはアンカー語の保持と母音操作への追従も見られ、今回の生成用途では有望だった。ただし、反復や意味の崩れた文章も増えた。

## 条件

保存済みの15秒・90 BPMの合成音声6本を使い、モデルだけを切り替えた。アンカーは「なし」「中立語：これ・ただ・いま・ことば」「テーマ語：夜・街・影・鼓動」の3条件、語尾の母音操作はoff/onの2条件である。onでは疑似CV音声のフレーズ末尾を `/a a/` にする。

各モデル・各条件20 decode、3モデル合計360 decode。seedは3579〜3598、temperature 0.6、最大64 token、best_of 1、length_penalty 1.0。全モデルでCPU・float32・同じpromptとprefixを使った。promptは「迷いを越えて　答えはまだ遠い／足取り重ねて　向かうその先／昨日の痛みも　力に変えて」、prefixは「そして」。出力の文字数などにはprefixを含めない。

`model.decode()`を直接呼び、`transcribe()`の無音判定による棄却は行わない。non-speech、言語切替、no-timestamps tokenはモデルごとのtokenizerに合わせて抑制した。同じ音声のEncoder出力を再利用し、Decoderの乱数seedは各sampleで設定した。入力WAVのハッシュと実行条件はmanifestへ保存した。

## 意味のある語を挿入しない条件

アンカーなしのoff/onを合わせた各40 decodeの結果。

|モデル|カナ読みが1モーラ以上出た割合|平均文字数|強い反復|promptのコピーが半数以上|
|---|---:|---:|---:|---:|
|tiny|100%|45.8|35.0%|20.0%|
|small|100%|53.7|20.0%|0.0%|
|large-v3|82.5%|13.2|5.0%|0.0%|

この音声とdecode条件では、tinyとsmallのほうが出力を続けやすかった。特にsmallはlarge-v3の約4.1倍の文字数だった。tinyでは反復とpromptのコピーが目立ち、出力量がそのまま文章の質へつながるわけではなかった。

ここで測ったのは曖昧な疑似音声への出力傾向である。人によるハルシネーション分類を行った発生率でも、通常の文字起こしでの誤り率でもない。

## 6条件全体

各モデル120 decodeを合算した値。

|モデル|平均文字数|強い反復|promptコピー|64 token上限到達|
|---|---:|---:|---:|---:|
|tiny|39.1|27.5%|14.2%|40.0%|
|small|49.8|19.2%|2.5%|56.7%|
|large-v3|17.0|2.5%|0.0%|14.2%|

smallの長い出力には無意味な疑似音節や崩れた日本語も含まれる。large-v3は短い一方、反復は少なかった。

## テーマ語の保持

テーマ語を挿入したoff/on各20回、合計40 decodeのうち、4語の読みが1語以上出た割合。

|モデル|アンカー認識|「夜・街・影・鼓動」の表記が1語以上出た割合|
|---|---:|---:|
|tiny|22.5%|10.0%|
|small|72.5%|72.5%|
|large-v3|80.0%|85.0%|

smallは文章を長く出しながらアンカー語も比較的保った。tinyでは、音声に入れたテーマ語の保持がかなり弱かった。読みの一致には同音異義語を含み、表記の一致には「今夜」などの複合語を含むため、両指標は同じではない。挿入語の直接転写は意味的なテーマ展開の証拠にはならない。

## 語尾母音への追従

フレーズ加重の語尾 `/a/` 率。各欄は語尾操作off → onを表す。

|モデル|アンカーなし|テーマ語あり|
|---|---:|---:|
|tiny|6.0% → 31.6%|2.0% → 43.1%|
|small|20.4% → 83.3%|31.6% → 71.3%|
|large-v3|18.0% → 22.5%|13.7% → 34.5%|

smallのアンカーなし条件では、語尾 `/a a/` も3.5% → 46.2%へ増えた。テーマ語ありでは0.6% → 7.8%だった。

強い反復・promptコピーと判定した出力を除いても、smallのアンカーなし条件の語尾 `/a/` は24.7% → 81.8%だった。ただし、残ったsample数はoffが14、onが18で、異なる集合を比較する補助的な確認である。

同じdecoder seedのoff/onを対応させ、decodeごとの語尾 `/a/` 率の差をbootstrapした結果は以下の通り。

|モデル|アンカーなし：平均差［95%区間］|テーマ語あり：平均差［95%区間］|
|---|---:|---:|
|tiny|+23.3［+7.5, +39.9］ポイント|+29.4［+9.0, +50.8］ポイント|
|small|+58.2［+40.8, +73.7］ポイント|+35.8［+19.7, +52.7］ポイント|
|large-v3|+6.8［−10.9, +26.0］ポイント|+10.1［−1.5, +23.0］ポイント|

率を計算できない出力を含む組は除外した。有効ペア数はアンカーなしがtiny/smallで20、large-v3で16。テーマ語ありが各18。フレーズ加重の表との差は集計単位による。

smallとtinyで母音操作への反応が見られた。ただし、off/onは `/a/` の配置だけでなく総量も異なる。この比較から「位置だけの効果」や「意味を保った押韻」まで断定はできない。

## 同じ音声・同じsample番号の出力

テーマ語あり・語尾操作on、trial_seed 3585の全出力。空白のみ読みやすく整形した。

tiny:

> 答えはまだ遠い　答えはまだ遠いactly　答えはまだ遠い　答えはまだ遠い　答えはまだ遠い　答えはまだ遠い　答えはまだ遠い　答えはまだ遠

small:

> 夜は吹いてた　アホこでほたたまでてこくいたたたちいてたてたた鐘つくいてたたつかてつくいたた骨頭すくときはた

large-v3:

> 夜を叩きつけたら　あそそそそ　街　目をつけたら　走り出されたら　影　見つけてたら　つかてつけたら　鼓動　あそそそそ

この例ではlarge-v3が最も文章としてまとまる。平均出力量の順位とは一致しない。前回紹介したlarge-v3の例に合わせたsampleであり、モデルごとの典型例を無作為抽出したものではない。

smallで別のsample（trial_seed 3581）を見ると、次の出力もある。

> は夜のせかた　馬鹿を出した街で駆けた　勝ちに出された影は向きでた　唾を告げた鼓動は駆けた　逃げ出した

文意は崩れているが、アンカー語と「た」で終わる連続した句を生成している。今回の探索では、smallが出力量と音響的な制御の両面で次の検証対象として有望だった。

## 指標の定義と制約

- カナ読みの有無は`pykakasi`と`jamorasep`による。自然な日本語文かどうかは判定しない。
- 強い反復はNFKC正規化・空白除去後、1〜32文字の同一単位が3回以上連続し、12文字以上かつ出力の50%以上を占める場合とした。
- promptコピーは、promptにも含まれる4文字列で覆われる文字が、正規化した出力の50%以上を占める場合とした。
- 反復・コピーの定義は出力を調べるための探索的な診断であり、意味的な品質評価ではない。言い換えや分散した反復は取り逃す。
- 語尾率は空白・句読点で分割した全フレーズの合算値。decode単位の率の平均とは異なる。
- 最大64 tokenに達した出力は打ち切られている。モデル間の文字数差は、この上限内での結果である。
- 音声は各条件1本、promptは1種類、temperatureは0.6だけ。20回は同じ音声のサンプリング反復であり、独立した20音源の評価ではない。
- 過去のlarge-v3集計とは混ぜず、今回の3モデルで再比較した。集計は凍結したテキストから再計算し、母音表の「レ」の欠落も修正した。

## 再現

```bash
uv run python scripts/run_model_size_comparison.py \
  --audio-dir generated_audio/lexical_anchor \
  --output-dir results/model_size_n20 \
  --models tiny small large-v3 \
  --temperature 0.6 --n-samples 20 --seed 3579 \
  --device cpu --threads 8
uv run python scripts/summarize_model_comparison.py results/model_size_n20
```

生テキストは`samples.jsonl`、入力条件は`manifest.json`、再集計結果は`analysis.json`に保存される。
